## 架构与接口

工程综合顶层为 `laser_lock_board_top.v`，内部实例化 `laser_lock_top.v`。后者保留需求中的完整调试总线接口；包装顶层把这些调试总线保留在 FPGA 内供 ILA 观察，避免把全部调试位当作外部 GPIO 而超出器件封装引脚数。主仿真直接验证包装顶层的完整输入输出链路。

200 MHz 差分参考时钟 → IBUFDS → MMCME4_BASE（1 GHz VCO）→ BUFG → 100 MHz 工作时钟。外部低有效复位和 MMCM 失锁触发复位；复位解除经过三级同步。RTL 数据模块全部使用工作时钟。

14 位有符号 ADC 抽象输入 → 输入寄存/偏置扣除/16 位限幅 → 可选 8 点滑动平均 → 设定值减测量值/可选反向/16 位限幅 → PI2D → 抗积分饱和及输出限幅 → 16 位有符号 DAC 抽象并行输出。

`adc_valid && adc_ready` 在工作时钟上升沿表示接受一个样本。发送端需在等待 ready 时保持 data/valid；控制器 busy 时不接受新样本。连续流源必须在前端增加 FIFO、抽取或采样使能，不能忽略 ready。`dac_valid` 为一个工作时钟周期的脉冲，数据随后保持至下一个输出。抽象 ADC/config 输入必须与 `clk_work_out` 同步；真实 ADC 采样域跨时钟需在适配层增加 CDC/FIFO。导出工作时钟仅作为集成接口，实际板级时钟输出需专用输出缓冲及真实时序约束。

从 ADC 接受到 DAC 有效为 12 个工作时钟周期，单个样本处理完成后 busy 再解除。连续握手最快每 14 个工作时钟接受一个样本，即约 7.14 MSample/s（100 MHz）。实际控制采样周期应固定，通过前端抽取降低至需要的伺服速率。该速率不是 AD9643 的物理采样速率或可锁定带宽。

默认上电控制器关闭，输出为 0。寄存器可读写但暂时没有 AXI/UART/SPI 命令解析器。`cfg_we && cfg_ready` 在上升沿完成写入；`cfg_ack` 随后有效一个周期，非法/只读地址还会置 `cfg_error`。空闲时配置优先于 ADC；busy 时配置请求需保持至 ready。

每次成功写配置都会清除积分、差分历史、滤波历史及 DAC 输出，防止新旧参数混用。建议先关闭使能、成组写参数、最后使能。此初版不提供无扰参数切换。复位恢复全部默认参数。

## 定点算法

`e[k] = saturate16(setpoint - filtered(adc - offset))`，反向位作用在最终误差限幅之前。

系数均为 32 位有符号整数，低 16 位为小数（系数实值 = 寄存器值 / 65536，范围约 -32768 至 +32767.999985）。例如 `1.0=65536`、`0.5=32768`、`-0.5=-32768`。

控制器实现：

```
P = Kp * e[k]
I_candidate = clamp(I_previous + Ki * e[k], +/- integral_limit * 65536)
D = Kd * (e[k] - e[k-1])
D2 = K2 * (e[k] - 2*e[k-1] + e[k-2])
u_candidate = P + I_candidate + D + D2 + bias * 65536
```

如果候选输出超出正限值且 `Ki*e>0`，或超出负限值且 `Ki*e<0`，拒绝此次积分增量；允许反方向增量帮助退出饱和。随后用选定的积分重新计算总输出，算术右移 16 位并限幅到 `[-output_limit,+output_limit]`。负数右移向负无穷取整，例如 -0.5 变为 -1。积分硬限幅发生和积分更新被拒绝分别有独立标志。

积分为 48 位有符号、16 小数位，存储已经乘过 Ki 的积分项。Ki 保持不变时等价于 `Ki*sum(e)`；参数更新清状态，因此不跨参数变更追溯历史。P/I 乘积 48 位、一阶差分 17 位及乘积 49 位、二阶差分 18 位及乘积 50 位，合成输出和积分试算均扩展到 64 位，避免先截断再限幅的溢出。Integral limit 最大 2147483647 个 DAC 整数码，与 48 位积分格式兼容。

这里按用户给出的数学式定义 PI2D 的 D2 为二阶差分。不能据此认定某台商业 PI2D 伺服器的传递函数相同。滤波导数、双积分等其它定义需取得设备资料后另行确认。

## 寄存器表

|地址|读写|含义|默认值|
|---|---|---|---|
|0x00|RW|Kp，32 位有符号 Q16|65536（1）|
|0x04|RW|Ki，每个接受样本的积分增益|256（1/256）|
|0x08|RW|Kd，每个接受样本的一阶差分增益|0|
|0x0C|RW|K2，每个接受样本的二阶差分增益|0|
|0x10|RW|对称输出限值，低 16 位；超过 32767 钳为 32767|16384|
|0x14|RW|bit0 使能、bit1 平均滤波、bit2 误差反向|0|
|0x18|RW|ADC 偏置，低 16 位有符号|0|
|0x1C|RW|光强锁定设定值，低 16 位有符号|0|
|0x20|RW|输出偏置，低 16 位有符号 DAC 码|0|
|0x24|RW|积分项限值，整数 DAC 码，钳至 0x7fffffff|32767|
|0x28|RO|状态，见下表|实时|
|0x2C|RO|最近控制误差，符号扩展至 32 位|实时|
|0x30|RO|最近 DAC 输出，符号扩展至 32 位|实时|
|0x34|RO|48 位积分的低 32 位|实时|
|0x38|RO|积分的高 16 位，符号扩展至 32 位|实时|
|0x3C|RO|已接受样本计数，32 位自然回卷|0|

读积分高低字时先停止发送 ADC，等待 busy=0，避免跨样本撕裂。非法读地址返回 0。`cfg_we` 持续有效且 ready 连续有效会每周期产生写事务，不能将写使能当作一次性锁存请求。

状态 bit0=MMCM locked，bit1=servo enable，bit2=busy，bit3=输出限幅，bit4=抗积分饱和拒绝增量，bit5=积分硬限幅，bit6=ADC 扣偏置限幅，bit7=误差限幅。各限幅位表示最近相应处理结果，读取完整一组状态应等待 `dac_valid` 或 busy=0。

## 调参与仿真

物理实验前需确认谐振峰斜边、误差极性及执行器方向。先 Ki/Kd/K2=0，从小 Kp 开始；确认负反馈后逐渐加 Ki。D 和二阶差分会放大高频噪声，默认关闭。8 点平均首个样本填充全历史，后续按最近 8 个接受样本平均；算术右移取整。滤波引入延迟，应纳入带宽设计。

离散系数已包含采样周期。若从连续域系数换算，在相应差分近似下 `Ki_discrete=Ki_cont*Ts`、`Kd_discrete=Kd_cont/Ts`、`K2_discrete=K2_cont/Ts^2`。改变有效采样周期需要重新整定系数，不能仅更改 ADC/DAC 适配模块。

`sim/tb_laser_lock_top.v` 使用真实 Vivado MMCM 仿真模型和独立 64 位参考计算，逐样本比较误差、控制输出、积分及保护位。覆盖符号/极值、四项运算、平均滤波、偏置/设定值/反向、输出/积分限幅、积分抗饱和恢复、寄存器非法访问、busy 写入等待及禁用行为。另用初始偏移、正弦扰动、缓慢漂移及确定性伪随机噪声驱动抽象离散植物模型，检查末段 RMS 降低和输出步变。

`sim/tb_pi2d_controller.v` 单独将完整 16 位正负极值交替送入控制器，验证 17/18 位差分、极值系数、负 Ki、运算期间系数和输入变化、计算中复位取消。2026-10-14 本机 Vivado 2024.1 实测：主测试 1731 个样本通过，控制器测试 59 组向量通过；抽象闭环初段 RMS=761.740872，末段 RMS=2.043282（ADC 码），末段最大输出步变=3（DAC 码）。

仿真只证明该抽象模型和 RTL 内部功能，不能证明未知激光器的捕获范围、锁定带宽、相位裕度或实验性能。当前不包含自动寻峰、斜边选择、失锁判断或自动重捕获；必须先用设定值及偏置把工作点放入合适斜边附近。

在 Vivado 的 Run Simulation 中运行 Run All；也可执行 `run_checks.cmd` 完成仿真、综合及 route。`scripts/create_project.tcl` 用于源文件迁移后首次创建工程，已有 xpr 时拒绝覆盖。`reports/` 提供实际检查记录及 `closed_loop.csv`。内置 ILA 为 6 个探针、1024 深度，采集误差 16 位、DAC 16 位、积分 48 位、状态 8 位、DAC valid、ADC ready，工作时钟为 100 MHz。实现中默认启用；测试台关闭 ILA。只需逻辑验证时，可将 sources_1 的顶层 generic 设置为 `ENABLE_ILA=0` 后重新综合。

Windows 构建脚本会用 Vivado 支持的 `-tempDir` 参数，把嵌套调试核项目放到短目录（默认 `C:/laser_lock_temp`），解决本机调试集线器在深层临时目录下读取原语脚本失败的问题。脚本先准备实现启动器，再执行启动器，最后保存报告。单独调用 `run_build.tcl` 时，Windows 需要 `-tclargs prepare` / 执行生成的 `runme.bat` / `-tclargs finish` 三步；直接使用 `run_checks.cmd` 即可。临时目录可用 `LASER_LOCK_TEMP` 环境变量指定为另一个可写、全英文且不含空格的短路径。

最终实际验证结果（含 ILA）：综合及 route 均完成，WNS=+0.740 ns、WHS=+0.011 ns，全部 5432 个可布线网络完成，内部未约束端点数为 0。资源为 2461 LUT、3548 寄存器，DSP/BRAM 详情见利用率报告。ILA 调试核的总线偏斜约束也通过，报告为 `reports/bus_skew.rpt`。

保留的 DRC 提示包括占位引脚造成的 NSTD-1/UCIO-1、DSP 进一步流水线优化建议等。没有隐藏或降级这些检查。一次综合因旧顶层的增量参考不适用而自动退回完整综合；最终实现使用完整综合结果。内部功能验证完成，板级约束需要取得真实硬件资料后补全。

## 约束与后续硬件适配

`constr/axau15_placeholder.xdc` 建立 200 MHz 输入时钟和暂定工作时钟接口延迟。没有填写 PACKAGE_PIN 或猜测 IOSTANDARD。可以用于内部综合和布局布线检查，但布局时自动分配的 I/O 不能作为板级引脚映射；NSTD-1/UCIO-1 不降级，不生成可上板 bitstream。

PZ-FL4322 教程描述 AD9643/AD9516/AD9122，示例使用 PZ7100-FH 平台。其示例引脚不得照搬到 AXAU15。当前不包含 AD9643 LVDS 解串、AD9516 SPI 初始化、AD9122 LVDS 时序及 SPI 配置，也不实现 NKT 特定协议或声称 16 位并行输出能直接驱动该 DAC。

后续主要替换 `adc_interface.v` 和 `dac_interface.v` 的物理适配层，必要时增加时钟/CDC/FIFO，并补充真实引脚、电平和源同步约束。激光器执行器电压范围、增益、偏置、保护限值和有效采样率确定后还需调整寄存器默认值、时钟、采样节奏及 PI2D 系数。数字码到电压的换算由实际 DAC 满量程及模拟驱动电路决定。
